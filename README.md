# Exemple tableau pour formation IA

Tableau de bord « attractivité et fidélisation » d'une association fictive du social et du médico-social (Cap Solidaire, Essonne), produit comme exemple pour l'intervention « Prise en main des outils IA » à l'Executive Master IRFASE (20/11/2026, PracTice, IMT-BS).

- Dix indicateurs avec repères nationaux (CNSA, données 2023) et seuils d'alerte, vue par établissement, suivi des dix actions du programme.
- Valeurs, statuts, commentaires et avancements modifiables dans la page ; copie de chaque tableau en CSV.
- Sur GitHub Pages, la page fonctionne en mode autonome : les saisies restent dans le navigateur de chaque personne (localStorage). La version partagée en direct est l'artifact claude.ai.

Données fictives : aucune donnée réelle d'association ou de personne.

`index.html` est fabriqué par `construire_index.sh` à partir de `tableau_de_bord_cap_solidaire.html` (source de l'artifact).
